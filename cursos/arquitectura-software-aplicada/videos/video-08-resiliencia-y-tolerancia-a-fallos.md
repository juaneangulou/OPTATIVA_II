# Video 8: Agentes de IA que revisan tu código en GitHub

## Título
Agentes de IA que revisan tu código en GitHub

## Resumen
Un agente de IA puede analizar una Pull Request y sugerir defectos, pruebas faltantes o riesgos. Su respuesta es una hipótesis que se debe contrastar con el requisito y el código; no es una aprobación automática ni reemplaza la revisión humana.

El uso seguro requiere dar contexto suficiente, limitar permisos, proteger datos y ejecutar pruebas. Quien integra el cambio sigue siendo responsable de aceptar o rechazar cada sugerencia.

## Ideas principales
- Una Pull Request propone cambios antes de integrarlos en la rama principal.
- El agente aporta observaciones, no una garantía de calidad.
- Pídele que cite líneas y distinga defectos probables de preguntas.
- No compartas secretos ni datos personales sin autorización.
- Revisa las sugerencias y ejecuta pruebas antes de integrar.

## Preguntas para pensar
- ¿Qué contexto necesita el agente para revisar una regla de pedidos?
- ¿Cómo comprobarías una sugerencia sobre un defecto?
- ¿Qué permisos y datos no necesita el agente para esa revisión?
